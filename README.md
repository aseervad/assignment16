✅ Objective:
To improve user experience by introducing modals for instructions and test results using a reusable component.

🧩 Key Features Implemented:
"View Instructions" button opens a styled modal with IELTS test guidelines

Modal is accessible (ESC key support and scroll-lock)

On timer expiry, a result modal automatically appears

All modals are reusable with dynamic content and title

Edit
